# Toy Text Classifier

A small experimental project for fine-tuning and evaluating DistilBERT-based text classifiers, with experiment tracking via Weights & Biases.

## Project Overview

This is a toy/learning project for text classification using Hugging Face `transformers` and PyTorch. It fine-tunes a `distilbert-base-uncased-finetuned-sst-2-english` model on the Rotten Tomatoes movie review dataset (binary sentiment classification), and logs training metrics to Weights & Biases (`wandb`). The project also includes a small pytest suite covering tokenization/preprocessing behavior.

## Data

### Source Data

- [Rotten Tomatoes movie review dataset](https://huggingface.co/datasets/cornell-movie-review-data/rotten_tomatoes) — loaded via the Hugging Face `datasets` library for training/evaluation.
- `tests/data/` contains small CSV/JSONL fixture files (`train.csv`, `test.csv`, `train.jsonl`, `test.jsonl`) used for local testing, generated by [utils/create_dummy_data.py](utils/create_dummy_data.py).

### Data Acquisition

Training data is pulled directly from the Hugging Face Hub at runtime via `datasets.load_dataset(...)`. Dummy fixture data for tests is generated locally rather than downloaded.

### Data Preprocessing

Text is tokenized using the DistilBERT tokenizer, with truncation and padding to a fixed max length, and dynamic padding at batch time via `DataCollatorWithPadding`. See [src/data.py](src/data.py) and the tokenization logic in [src/distilbert-wandb.py](src/distilbert-wandb.py).

## Code Structure

```bash
├── data/                    # (empty) local data directory
├── saved_models/
│   └── distilbert_orig/     # locally cached base DistilBERT model + tokenizer
├── src/
│   ├── main.py               # entry point (WIP)
│   ├── data.py                # dataset loading helpers
│   ├── save_model.py          # downloads and saves base DistilBERT model/tokenizer locally
│   ├── distilbert-wandb.py    # training loop with wandb logging (Trainer-style config)
│   └── wandb-test.py          # minimal wandb logging example/sanity check
├── tests/
│   ├── conftest.py            # shared pytest fixtures
│   ├── test_data.py           # data preprocessing tests
│   ├── test_main.py           # tokenization tests
│   ├── test_helpers.py
│   └── data/                  # small CSV/JSONL fixtures for tests
├── utils/
│   └── create_dummy_data.py  # generates dummy CSV/JSONL fixture data
├── pyproject.toml
└── uv.lock
```

### Running the tests

```bash
pytest
```

### Training

```bash
python src/save_model.py         # one-time: download and cache the base model locally
python src/distilbert-wandb.py   # fine-tune with wandb logging
```

## Results and Evaluation

Training runs are logged to Weights & Biases (see the `wandb/` run directories). No formal evaluation metrics or benchmark comparisons have been recorded yet — this is currently a work-in-progress experimentation project.
